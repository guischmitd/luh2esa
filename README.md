# LUH2ESA

A collection of models and experiments aimed at recovering ESA satellite land cover fractions from LUH2.

## Components
- `recover` package including the ML model interface and pipelines as well as general utilities to manipulate and visualise the datasets.
- `noteboooks/` dir with reproducible experiments to evaluate modeling approaches using different cross-validation strategies.

## Quickstart
System requirements:
- `python` version >= 3.11 annd < 3.14
- `uv` for package management

Install dependencies:
```bash
uv sync
```
